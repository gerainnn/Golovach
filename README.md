# Golovach

Telegram-бот с AI-командой агентов: оркестратор, два кодера, критик и судья.
Агенты спорят между собой, финальный ответ проходит через «слепого» judge.

## Быстрый старт

```bash
git clone https://github.com/gerainnn/Golovach.git
cd Golovach
python setup.py
```

Один скрипт делает всё:
1. Проверяет Python ≥ 3.10
2. Создаёт виртуальное окружение
3. Устанавливает зависимости
4. Открывает интерактивную настройку (провайдеры, модели, параметры)
5. Предлагает сразу запустить бота

## Архитектура

```
Telegram → Classifier ──┬── [general] → Orchestrator (стриминг) → ответ
                        │
                        └── [code]    → Orchestrator (план)
                                       → Coder A ╲
                                                   ╳  Debate (N раундов)
                                         Coder B ╱        ↑ Critic
                                       → Judge → ответ
```

- **Мульти-провайдер**: подключай сколько хочешь провайдеров (Kiro, Groq, OpenRouter, Cerebras, Together, OpenAI...)
- **Автодетект моделей**: при добавлении провайдера скрипт запрашивает `/v1/models` и показывает список
- **Включение/выключение моделей**: выбираешь какие модели попадают в общий пул
- **Роли с разными моделями**: каждый агент может работать на своей модели из своего провайдера
- **Настраиваемая инфраструктура**: температура, max_tokens, режим судьи, промпты — всё через UI

## Структура

| Файл | Назначение |
|------|-----------|
| `setup.py` | Единая точка входа: установка + настройка + запуск |
| `configure.py` | Интерактивная настройка (можно перезапускать отдельно) |
| `main.py` | Точка входа бота |
| `bot.py` | Telegram-хендлеры (aiogram v3), стриминг, /settings |
| `pipeline.py` | Classify → debate → judge |
| `agents.py` | Классы агентов |
| `prompts.py` | Системные промпты (генерируются из settings.json) |
| `providers.py` | OpenAI-совместимый клиент + Router |
| `config.py` | Чтение .env + settings.json + providers.json |

## Конфигурационные файлы (не коммитятся)

| Файл | Содержимое |
|------|-----------|
| `.env` | Telegram token, назначение ролей, admin IDs |
| `providers.json` | Провайдеры (имя, URL, ключ, включённые модели) |
| `settings.json` | Температура, max_tokens, режим судьи, промпты, параметры пайплайна |

## Настройка через меню

```bash
python configure.py
```

Главное меню:
- **Добавить провайдера** — имя + URL (или пресет) + ключ → автодетект моделей → выбор какие включить
- **Управление моделями** — вкл/выкл модели у существующего провайдера
- **Назначить модели на роли** — единый пул всех активных моделей со всех провайдеров
- **Настройки инфраструктуры**:
  - Раунды дебата (0–10)
  - Режим судьи: merge_or_pick / approve_or_reject / rewrite
  - Температура по ролям (0.0–2.0)
  - Max tokens по ролям
  - Стриминг в Telegram (вкл/выкл)
  - Параллельность кодеров
  - Показывать ход мысли пользователю
  - Язык ответов (ru / en / auto)
  - Anti-fluff (убирает воду и дисклеймеры)
  - Таймаут LLM
  - Кастомные системные промпты по ролям

## Команды бота в Telegram

| Команда | Действие |
|---------|----------|
| `/start` | Приветствие |
| `/ping` | Проверка жизни |
| `/settings` | Показать текущие модели и параметры |
| `/settings <role> <model>` | Сменить модель роли на лету |
| `/settings rounds <N>` | Изменить кол-во раундов дебата |

## Рекомендации по моделям

**Ключевой принцип**: Coder A и Coder B должны быть из разных семей моделей — иначе дебат бессмыслен.

| Роль | Рекомендация |
|------|-------------|
| Classifier | Самая дешёвая/быстрая (gpt-4o-mini, gemini-flash, llama-8b) |
| Orchestrator | Сильная reasoning-модель (claude-sonnet, gpt-5, gemini-pro) |
| Coder A | Сильный кодер семьи X (claude-sonnet) |
| Coder B | Сильный кодер семьи Y (gpt-5 или deepseek) |
| Critic | Другая семья (deepseek, qwen) |
| Judge | Самая сильная, с чистым контекстом |

## Требования

- Python ≥ 3.10
- Telegram bot token (от @BotFather)
- Хотя бы один OpenAI-совместимый провайдер с API-ключом
